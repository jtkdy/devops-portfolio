## 폴더 구성

- **`IBM KTS/`** — 고객사별 프로젝트 기록 (IDC 이전, 신규 서버 구축 등 5건)
- **`제주항공/`** — 시간순 프로젝트 기록 8건 (EKS 전환, 미들웨어 전환, 비용 최적화, 장애 대응 등)
- **`TelePIX/`** — 기술 도메인별 구조
  - `01. infra` — Terraform 인프라 관리, AWS/온프렘 작업
  - `02. security` — OS 하드닝, 네트워크 IDS, IAM Roles Anywhere, Wazuh, Prowler
  - `03. incidents` — 장애/인시던트 대응 기록
  - `04. 개발자 포탈` — 사내 개발자 포탈 구축 시리즈
  - `05. monitoring` — Grafana 기반 모니터링 스택 구축 시리즈
  - `00. projects` — 여러 도메인에 걸친 작업을 프로젝트 단위로 시간순 재정리한 목차 (실제 문서는 위 도메인 폴더에 그대로 두고 링크만 모음)

## 이 저장소 보는 법

이 문서들은 원래 Obsidian vault로 관리됩니다. Obsidian으로 열면 문서 내부의 `[[문서명]]` 링크를 클릭해 자유롭게 탐색할 수 있습니다.

**GitHub 웹에서 볼 때는 `[[문서명]]` 형식의 내부 링크가 렌더링되지 않습니다** (Obsidian 전용 문법이라 GitHub Markdown이 지원하지 않음). 이 경우 위 표의 링크나 각 폴더의 `00-index.md`를 직접 열어 탐색하는 것을 권장합니다.
