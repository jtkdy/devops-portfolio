## 배경

신규 Oracle 서버(장비 S914) 구축을 위한 OS 환경 설정 지원 필요

## 접근

Oracle RAC 특성에 맞춰 OS 파라미터를 표준 값이 아닌 워크로드 기준으로 조정

- **VMM(minperm%/maxperm%, lru_file_repage)** — Oracle SGA가 쓰는 공유메모리를 파일 캐시가 밀어내지 않도록 조정, DB 성능 저하 방지
- **System Block Size** — Oracle DB block size와 정렬, I/O 효율 확보
- **SSH LoginGraceTime** — 장시간 걸리는 구축·배치 작업 중 세션이 끊기지 않도록 여유 확보
- **User Process Parameters(ulimit: nproc/nofile)** — RAC 백그라운드 프로세스가 많아 기본값으로는 프로세스/파일 핸들 부족
- **Network Parameters(tcp_recvspace/sendspace 등)** — RAC 노드 간 트래픽 처리량 확보

## 구현

- 신규 서버 설치 및 OS 구축 (장비 S914)
- AIX 설치 및 Oracle 환경 구축
- 필요 파일셋 설치 및 RAC 구성 요소 설정
- aix system VMM, System Block Size, SSH LoginGraceTime, User Process Parameters, Network Parameters 튜닝

활용 기술 — AIX
