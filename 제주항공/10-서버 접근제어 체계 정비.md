## 배경

개발자·협력사의 서버 접근이 통제 없이 이뤄지고, CI/CD 파이프라인(Jenkins)에 장기 액세스키가 방치된 구조
계정·권한 관리와 서버 접근 경로를 정비할 필요 대두

## 접근

계정·권한 그룹 관리는 MS Active Directory GPO로, 서버 단위 접근 통제는 타사 서버접근제어(SAC) 솔루션으로 이원화
SAC 솔루션은 자체 구축이 아니라 타사 제품을 운영·관리하는 방식
EKS 파드 단위 AWS 권한은 장기 액세스키 대신 IRSA(IAM Roles for Service Accounts)로 전환

## 구현

- MS Active Directory GPO로 계정·권한 그룹 관리 체계 수립
- 타사 서버접근제어(SAC) 솔루션 운영·관리
- Jenkins 파이프라인의 장기 액세스키를 IRSA(EKS 서비스어카운트)·EC2 Instance Profile 방식으로 전환·회수

## 결과

Jenkins 장기 액세스키 제거, 계정(AD)·서버(SAC) 이원 통제 체계 운영
